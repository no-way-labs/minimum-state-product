This note records the algebraic/empirical relations suggested by the exact

This strongly suggests we are not looking at many unrelated feature choices.
We are seeing different coordinate systems on a much smaller quotient space.

## 2. Obvious count identities

Let the interior positions be `2..n-3`, with interior length `L = n-4`.

Write

- `c0 = count_val_0`
- `c1 = count_val_1`
- `c2 = count_val_2`
- `S = interior_sum`

Then always:

- `c0 + c1 + c2 = L`
- `S = c1 + 2*c2`

So:

- `(S, c0)` determines `(c1, c2)`
- `(S, c1)` determines `(c0, c2)`
- `(S, c2)` determines `(c0, c1)`

This explains why `interior_sum` can often be swapped with one count statistic
in exact residual bases.

There is also a useful outgoing-pair decomposition. For each interior value
`a in {0,1,2}`,

`count_val_a = Σ_b count_pair_ab`.

In particular,

- `count_val_2 = count_pair_20 + count_pair_21 + count_pair_22`
- since `exp2 = count_pair_20 + count_pair_21`, we get
  `count_val_2 = exp2 + count_pair_22`

This is useful on the reduced-prefix `FutureFc` branch: recovering `exp2` is
equivalent to recovering the interior `2`-mass once `count_pair_22` is known.

## 3. Empirical pair-count dualities

Across the exact subset lists, the following substitutions recur:

- `weight_pair_01, weight_pair_02` <-> `weight_pair_10, weight_pair_12`
- `weight_pair_00` <-> `weight_pair_11`
- `even_val_sum` <-> `odd_val_sum` in several higher-`n` exact bases

This strongly suggests that, once the base invariants are fixed, the remaining
slice code depends only on a small number of pair-count directions rather than
on all raw pair statistics separately.

## 4. Working interpretation

The residual slice code appears to live in a small quotient of the weighted
adjacent-pair statistics, with many raw features collapsing to the same
information after conditioning on:

- `FutureFc`
- boundary 6-tuple
- proof107 invariants

So the real object is probably:

- not the raw feature set,
- but a small algebra generated by interior value counts and a few weighted pair
  directions.
