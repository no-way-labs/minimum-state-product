# Minimizing the State Product for Self-Stabilizing Token Rings

## 1. Dijkstra's Self-Stabilization Problem

In 1974, Dijkstra posed the following question [1]: can local actions by
processors with only local information guarantee convergence to a global
property — specifically, mutual exclusion — regardless of the initial state?

**Setup.** Consider $n$ processors $P_0, P_1, \ldots, P_{n-1}$ arranged in a
circular ring. Processor $P_i$ has $m_i$ states $\{0, 1, \ldots, m_i - 1\}$.
Let $p_i$ denote the current state of $P_i$. The left neighbor of $P_i$ is
$P_{i-1}$ and the right neighbor is $P_{i+1}$ (indices mod $n$). Each
processor has a transition function

$$p_i' = f_i(p_{i-1},\, p_i,\, p_{i+1})$$

that depends only on its own state and its two neighbors' states. Processor
$P_i$ is said to be *privileged* (able to move) when
$f_i(p_{i-1}, p_i, p_{i+1}) \neq p_i$.

A *configuration* is a tuple $p_0 p_1 \cdots p_{n-1}$. A *central daemon*
nondeterministically selects one privileged processor at each time step to
execute its move. Configurations are partitioned into "good" and "bad."

**Five properties** are required of a valid system:

1. **Liveness.** In every configuration $p_0 \cdots p_{n-1}$, at least one
   processor can move.
2. **Mutual exclusion.** In every good configuration, exactly one processor
   can move.
3. **Closure.** Every move from a good configuration leads to another good
   configuration.
4. **Convergence.** No sequence of moves from bad configurations cycles
   back to itself. (Equivalently: every execution from any initial
   configuration reaches a good configuration in finitely many steps.)
5. **Fairness.** Every cycle of moves through the good configurations
   includes a move by each processor. (No processor starves.)

A system satisfying all five properties is called *self-stabilizing*.

## 2. Dijkstra's Three Solutions

Dijkstra gave three constructions [1]. In his notation, $L$, $S$, $R$
denote the states of the left neighbor, self, and right neighbor
respectively. Machine $P_0$ is the "bottom machine" and $P_{n-1}$ (his
$P_N$) is the "top machine."

**Solution 1** ($K$-state uniform, $K > n$). All processors share the same
number of states $K \geq n+1$. One processor ($P_0$) is distinguished:

$$f_0(L, S, R) = \begin{cases} (S+1) \bmod K & \text{if } L = S \\ S & \text{otherwise}\end{cases}$$

$$f_i(L, S, R) = \begin{cases} L & \text{if } L \neq S \\ S & \text{otherwise}\end{cases} \qquad (1 \leq i < n)$$

State product: $K^n$. Requires $K \geq n$, so the product grows as $n^n$.

**Solution 2** (4-state, non-uniform). Each machine uses two booleans
$(xS, upS)$. The bottom machine has $upS = \text{true}$ fixed; the top has
$upS = \text{false}$ fixed. Bottom and top are therefore 2-state machines;
the $n-2$ middle machines are 4-state. State product: $2 \cdot 4^{n-2}
\cdot 2 = 4^{n-1}$.

*Note:* As the seminar discovered, this is actually a *line* solution (the
two ends don't look at each other), not a ring solution [2, p. 76].

**Solution 3** (3-state uniform). Each machine has states $\{0, 1, 2\}$,
with arithmetic mod 3:

For the bottom machine:

$$f_0(L,S,R) = \begin{cases} (S-1) \bmod 3 & \text{if } (S+1) \bmod 3 = R \\ S & \text{otherwise}\end{cases}$$

For the top machine:

$$f_{n-1}(L,S,R) = \begin{cases} (L+1) \bmod 3 & \text{if } L = R \text{ and } (L+1) \bmod 3 \neq S \\ S & \text{otherwise}\end{cases}$$

For middle machines ($1 \leq i < n-1$), two privileges:

$$f_i(L,S,R) = \begin{cases} L & \text{if } (S+1) \bmod 3 = L \\ R & \text{if } (S+1) \bmod 3 = R \\ S & \text{otherwise}\end{cases}$$

State product: $3^n$. Dijkstra published this without proof; the proof
appeared only in 1986 [3].

## 3. The Open Problem

In winter 1985, Knuth posed the following optimization question to his
CS 204 Problem Seminar at Stanford [2, p. 68]:

> **Problem.** Let $M_n$ be the minimum value of the product
> $m_0 \cdot m_1 \cdots m_{n-1}$, taken over all valid self-stabilizing
> systems on $n$ processors in a ring. Find $M_n$, or determine its
> asymptotic growth rate.

The critical observation motivating this question: the processors need not
all have the same number of states. Dijkstra's Solution 2 already exploits
this (2-state endpoints, 4-state middle). Tchuente [4] had shown that if
all $m_i$ are equal, then $m_i \geq 3$ is necessary. Knuth generalized to
the product.

**Known bounds:**

| Bound | Value | Source |
|---|---|---|
| Upper | $M_n \leq 3^n$ | Dijkstra's Solution 3 [1] |
| Lower | $M_n > 2^n$ for $n > 4$ | Proved in seminar [2, pp. 70–75] |
| Small cases | $M_n = 2^n$ for $n \leq 4$ | Gray code construction [2, p. 70] |

**The central open questions** (from [2, p. 68]):

$$\text{Is } \limsup_{n \to \infty} M_n^{1/n} < 3 \text{ ?}$$

$$\text{Is } \liminf_{n \to \infty} M_n^{1/n} > 2 \text{ ?}$$

In other words: can one asymptotically beat 3 states per processor on
average? And is 2 states per processor on average asymptotically
impossible?

## 4. Partial Results from the Seminar

The following results were obtained during the five sessions (Feb 28 –
Mar 12, 1985) devoted to Problem 4 [2, pp. 67–79].

### 4.1 Gray code works for $n \leq 4$

For $n = 3$: the 8 binary configurations form a Gray code cycle

$$000 \to 001 \to 011 \to 010 \to 110 \to 111 \to 101 \to 100 \to 000$$

where each step flips exactly one bit. Declaring all configurations "good"
trivially satisfies properties (1)–(5). The same construction works for
$n = 4$ with the 16-element Gray code. Thus $M_3 = 8$, $M_4 = 16$.

### 4.2 Five binary processors cannot self-stabilize

This is the key lower bound argument, developed over the March 5 and
March 7 sessions.

**Quasi-unidirectionality.** In any valid all-2-state system, once a
processor $P_i$ moves, the next move must be by $P_{i+1}$ or $P_{i-1}$
(an immediate neighbor). Moreover, once movement starts in a direction, it
must continue in that direction — the baton cannot reverse through the same
2-state processor it just traversed. DEK proved: a processor in a 2-state
system would never want to move twice in a row.

**Bad cycle for $n = 5$.** DEA exhibited an explicit bad cycle exploiting
the forced unidirectionality: with 5 binary processors, three "waves" can
chase each other around the ring indefinitely, never converging.

**Generalization.** RFC observed that the argument extends: any ring
with four or more consecutive 2-state processors is impossible.

### 4.3 ARG's LCM constraint

ARG (working with DEA and AAM) proved: in any valid scheme that places
$2N$ non-adjacent 2-state processors around the ring, the least common
multiple $L$ of the state counts in each block of processors between
consecutive 2-state processors must satisfy $L \geq N + 1$. Otherwise, one
can construct a cycle of bad configurations that look locally good to each
processor.

### 4.4 ARG's conjecture

ARG conjectured that no working scheme can have more than a constant
number of 2-state processors as $n \to \infty$. This remains unproved.

### 4.5 The wave-filter perspective

DEK offered an intuition for why the problem is hard [2, p. 76]: one
wants processors that filter $k$-waves down to $\lceil k/2 \rceil$-waves
on every lap around the ring. It is easy to build a filter to
$\lfloor k/2 \rfloor$-waves, but a system that achieves this goes dead (no
processor can move in steady state). The ceiling version is the hard
direction.

### 4.6 Computer search

On the final day (March 12), DEK outlined how to verify candidate systems
by computer: enumerate configurations, compute successors, check that
good configurations form a single cycle, and verify no bad configuration
cycles exist (via iterative removal of "bad" source vertices in O(n) time,
rather than transitive closure). The state space grows as
$\prod m_i$, making exhaustive search feasible only for small $n$.

## 5. Subsequent Work (Not Resolving the Problem)

The following results appeared after 1985 and are related to
self-stabilizing token rings, but none resolves the product-minimization
question.

**Tchuente (1981) [4].** If all processors are uniform (same $m$), then
$m \geq 3$. This motivated Knuth's non-uniform generalization.

**Burns and Pachl (1989) [5].** Self-stabilizing rings with *no*
distinguished processor require $\Theta(n)$ states per processor (later
refined to $\Theta(n^2 / \ln n)$ for deterministic uniform rings).
Orthogonal to the product question, which allows a distinguished processor.

**Dijkstra (1986) [3].** Belated proof of Solution 3 correctness.

**Ghosh (1993) [6].** Under a central daemon with deterministic execution,
a minimum of 3 states per machine is required for self-stabilizing token
rings. This is the uniform lower bound; does not address non-uniform
products.

**Gouda and Haddix (1996) [7].** First stabilizing unidirectional
deterministic token ring where each process has a constant (8 = 3-bit)
number of states, independent of ring size. Addresses a different model
(unidirectional, read-only from one neighbor).

**Beauquier and Debas (1995) [8].** Optimal 3-state algorithm for
bidirectional non-uniform rings, with tight $O(n^2)$ stabilization time.
Does not address product minimization.

**Hoepman (1999) [9].** Shows Dijkstra's K-state solution (Solution 1)
stabilizes even when $K = n$ (not just $K > n$), and that $K = n-1$ is
insufficient. Tightens bounds for Solution 1 but does not improve $3^n$.

**Blin, Le Bouder, Petit (2024) [10].** Establish $O(\log \log n)$ bits per
node as both sufficient and necessary for self-stabilizing token circulation
on general rooted networks. Different model (rooted networks, unfair
daemon); measures bits rather than product of state counts.

**Automated synthesis (Protocon) [11].** Exhaustive search tool verifying
that 5 states per process is the minimum for unidirectional self-stabilizing
token rings. For bidirectional rings, 3 states suffice. Does not address
non-uniform product optimization.

## 6. What Remains Open

The state of knowledge, 40+ years on:

1. **The gap $2^n < M_n \leq 3^n$ is untouched for large $n$.** No
   construction beats $3^n$. No lower bound exceeds $2^n$ (other than
   the fact that $M_5 > 32$).

2. **Exact values are unknown for $n \geq 5$.** Even $M_5$ has not been
   determined. Computer search is feasible here: the state space for
   candidate systems with small $m_i$ is manageable.

3. **ARG's conjecture is unproved.** Can a valid system have
   $\omega(1)$ binary processors as $n \to \infty$?

4. **No sub-exponential gap.** It is not even known whether $M_n^{1/n}$
   converges, let alone what its limit might be.

5. **The wave-filter approach is unexplored.** DEK's intuition about
   $\lceil k/2 \rceil$-wave filters was never formalized.
